# Analyze official brief

1. Read `AGENTS.md`, then actual organizers' brief and sample files; inspect file contents rather than making assumptions.
2. Populate or verify `docs/CHALLENGE_BRIEF.md` using `docs/BRIEF_TEMPLATE.md`.
3. Classify task using `docs/SCENARIOS.md`; map exact score and hard requirements.
4. List verified facts versus unresolved questions; quote conflicts verbatim.
5. Choose a simple, valid baseline and matching evaluation plan using `docs/EVALUATION.md`.
6. Provide ≤ 1 hour baseline milestone, owner, checks and failure recovery.
7. Stop before large implementation unless explicitly asked to continue.
